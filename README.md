# soundboardio/.github

Defaults for every repository in the organization, and the organization profile.

- `profile/README.md` is what [github.com/soundboardio](https://github.com/soundboardio) shows.
- `.github/FUNDING.yml` puts the Sponsor button on every repository.
- `.github/ISSUE_TEMPLATE/` holds the issue forms (a missing quote, a missing reference) and the chooser's contact links. They apply to every repository that has no issue templates of its own.
